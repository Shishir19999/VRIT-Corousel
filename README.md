# Vertical Carousel

A plain HTML/CSS/JS vertical card carousel. Three cards are stacked (above / center / below); click and drag the carousel up or down (more than 50px) to rotate the cards.

No build step: open `index.html` in a browser.

Files: `index.html` (markup), `style.css` (card positions and transitions), `script.js` (drag handling and class rotation).
